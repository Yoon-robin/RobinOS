# RobinOS 소개 영상

RobinOS를 40초 동안 보여 주는 모션그래픽 영상이에요. 1920×1080, 60fps에 소리가 들어 있어요. 2026-10-12에 만들었어요.

영상 편집 프로그램 없이 **웹 페이지(HTML/CSS + GSAP)로 짜고, 헤드리스 크롬으로 한 프레임씩 찍어 mp4로 묶어요.** 실시간 화면 녹화가 아니라서 PC가 느려도 프레임이 빠지지 않아요. 같은 방식으로 ITCS Connect 광고(`itcsconnect.xyz/itcs-connect-app/ad`)를 만들어 본 적이 있어요.

```bash
cd promo/intro
npm install            # gsap 하나
npm run fonts          # Geist, Pretendard 받기 (scripts/fetch-fonts.sh와 같은 릴리스·체크섬)
npm run preview        # 브라우저 미리보기: 클릭·Space = 재생/멈춤, ←/→ 2초 이동, 주소 끝에 ?t=12 → 12초부터
npm run render         # out/robinos-intro.mp4 (60fps, 몇 분 걸려요)
npm run render:draft   # out/robinos-intro-draft.mp4 (30fps, 빨리 확인할 때)
node render.mjs --stills=4.5,12,27   # 그 시각만 out/stills/*.png로 찍기
```

필요한 것: Node 18 이상, 크롬(다른 곳에 있으면 `CHROME=<경로>`), libx264와 aac가 들어 있는 ffmpeg(PATH에 두거나 `FFMPEG=<경로>`). Remotion이 받아 둔 ffmpeg는 DLL이 `../lib`에 있는데, `render.mjs`가 그 폴더도 PATH에 넣어 줘요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `cues.js` | **시간표.** 장면이 바뀌는 시각, 장면 안의 사건 시각, 효과음. 화면과 소리가 둘 다 이 숫자를 읽어요. 시각은 여기서만 바꿔요 |
| `index.html`, `style.css` | 장면의 생김새. 색과 모서리는 `desktop/shell/Theme.qml`(zinc, 다크)과 같아요 |
| `main.js` | 움직임(GSAP 타임라인 하나), 저절로 움직이는 것(커서 깜빡임, 타자, 점 격자) |
| `music.mjs` | 배경음악과 효과음을 코드로 합성해요 → `out/audio.wav` |
| `render.mjs` | 헤드리스 크롬 → 프레임마다 `__video.seek(t)` → 찍기 → ffmpeg |
| `server.mjs`, `preview.mjs`, `fonts.mjs` | 127.0.0.1 로컬 서버, 미리보기, 글꼴 받기 |
| `assets/` | 실제 화면. 부팅 테스트(`build/boot-test`, 2026-10-12)와 설치 테스트(`snapshots-02-grub-menu-snapshots.png`)가 찍은 1600×900 스크린샷이에요 |

| 12–15 | 런처: "notepad"를 찾으면 텍스트 편집기가 "윈도우의 메모장에 해당해요"로 나오는 실제 화면에 카메라가 다가가요 |
| 15–18 | 빠른 설정 실제 화면 |
| 18–21.5 | 터미널에 `ipconfig`를 치면 리눅스 명령(`ip a`)을 알려 주는 힌트(`desktop/bash/robinos-hints.sh`의 실제 문구), 이어서 `robinctl learn show 1`을 쳐요 |
| 21.5–24 | 미션 1의 실제 터미널 화면, "미션 45개를 실제 터미널에서 풀어요" |
| 24–27 | "켜는 순간부터 RobinOS예요": 부팅 메뉴, 로그인, 바탕 화면(오른쪽 클릭 메뉴와 독)의 실제 화면이 한 박에 하나씩 |
| 27–30 | 다크 런처 위로 라이트 런처가 밀려 들어와요(와이프). "다크·라이트를 바꾸면 바, 런처, 터미널이 같이 바뀌어요" |
| 30–34 | "업데이트로 망가져도 되돌려요": 부팅 메뉴의 스냅샷 목록(설치 테스트 화면). 스냅샷 줄에 불이 들어와요 |
| 34–40 | Arch Linux · Hyprland · Quickshell · Btrfs 스냅샷 · 한글 입력, 울새가 한 번 더 내려앉으며 끝 로고, GitHub 주소와 "v0.2 프리뷰" |

## 지킨 것

- **실제로 있는 기능과 명령만** 넣어요. 화면은 모두 테스트가 찍은 실제 스크린샷이고, 터미널 장면은 `robinos-hints.sh`의 문구를 그대로 옮겼어요. 문구는 대부분 제품 안의 문장(환영 마법사, README)에서 가져왔어요.
- 구호는 쓰지 않아요. 보여 주는 화면이 말하게 해요(ITCS 광고 때 "인트로가 오글거린다"는 피드백을 반영했어요).
- **보안은 앞세우지 않아요**(2026-10-12 Robin: "보안은 강조하지마"). 10월 10일에 정한 방향대로, 직접 만든 화면으로 매일 쓰는 OS를 보여 줘요. 보안 학습은 여러 기능 중 하나예요. 부팅 메뉴의 "Security Learning Workstation"과 로그인 화면 아래의 보안 학습 문구는 카메라가 잘라 내요(`data-cam`, `camAt`). 제품 문구를 고치면(10월 10일 방향 브랜치 `claude/eoseohae-7nleia`의 T-151) 스크린샷을 새로 찍어 바꿔요.
- 글 한 줄은 1초 넘게 화면에 떠 있어요.
- 움직임: 나타날 때는 흐림 + 아래에서 위로 + 투명에서 불투명(0.6~0.9초, 튀지 않는 감속 곡선), 사라질 때는 그보다 작고 빠르게(0.38초)예요. 터미널 출력은 실제 터미널처럼 애니메이션 없이 바로 나타나요.
- 소리도 전부 코드로 합성해서 저작권 걱정이 없어요.

## 함정

- **CSS transition/animation은 쓰지 않아요.** 녹화는 타임라인을 프레임마다 멈춰 놓고 찍어서, CSS가 혼자 움직이면 프레임마다 달라져요. 저절로 움직이는 것은 `main.js`의 `ambient(t)`가 t만 보고 계산해요.
- **`file://`로 열면 안 돼요.** 크롬이 ES 모듈과 글꼴을 막아요. 그래서 로컬 서버를 띄워요.
- 터미널 줄은 `.line`에만 `white-space: pre`를 줘요. 감싸는 요소에 주면 HTML 줄바꿈이 빈 줄로 그려져요.
- 마지막 장면을 숨기는 `tl.set`을 영상 길이 뒤에 두면 타임라인이 그만큼 길어져요. 마지막 장면은 숨기지 않아요(`scene(el, from, null)`).
- 스크린샷 안의 카메라(`camAt`)는 화면 가장자리가 보이지 않게 위치를 잘라 줘요. 확대 배율을 바꿀 때는 `node render.mjs --stills=...`로 그 장면을 다시 찍어 봐요.
- 결과물(`out/`)과 글꼴(`fonts/`)은 git에 올리지 않아요.
