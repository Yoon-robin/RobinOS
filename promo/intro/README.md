# RobinOS 소개 영상

RobinOS를 41초 동안 보여 주는 모션그래픽 영상이에요. 1920×1080, 60fps에 소리가 들어 있어요. 2026-10-12에 만들었어요.

영상 편집 프로그램 없이 **웹 페이지(HTML/CSS + GSAP)로 짜고, 헤드리스 크롬으로 한 프레임씩 찍어 mp4로 묶어요.** 실시간 화면 녹화가 아니라서 PC가 느려도 프레임이 빠지지 않아요.

```bash
cd promo/intro
npm install            # gsap 하나
npm run fonts          # Geist, Pretendard 받기 (scripts/fetch-fonts.sh와 같은 릴리스·체크섬)
npm run preview        # 브라우저 미리보기: 클릭·Space = 재생/멈춤, ←/→ 2초 이동, 주소 끝에 ?t=12 → 12초부터
npm run render         # out/robinos-intro.mp4 (60fps, 몇 분 걸려요)
npm run render:draft   # out/robinos-intro-draft.mp4 (30fps, 빨리 확인할 때)
node render.mjs --stills=4.5,12,27   # 그 시각만 out/stills/*.png로 찍기
```

필요한 것: Node 18 이상, 크롬(다른 곳에 있으면 `CHROME=<경로>`), libx264와 aac가 들어 있는 ffmpeg(PATH에 두거나 `FFMPEG=<경로>`). Remotion이 받아 둔 ffmpeg는 DLL이 `../lib`에 있는데, `render.mjs`와 `music.mjs`가 그 폴더도 PATH에 넣어 줘요.

**녹화 속도**: 프레임마다 시각을 정해 멈춰 놓고 찍는 방식이라 구간을 나눠 동시에 찍어도 결과가 같아요. `render.mjs`는 크롬 여러 개(기본: CPU 스레드의 3분의 1, 최대 6개)가 구간을 하나씩 맡아 조각 mp4를 만들고, ffmpeg가 다시 압축하지 않고 이어 붙여요. 프레임은 JPEG 95로 찍고(`--png`면 무손실), x264는 `medium`이에요(`--preset=slow`). 2026-10-12 robin PC(16스레드)에서 크롬 5개로 41초 영상이 72초 걸렸어요(크롬 하나, PNG, `slow`일 때는 약 5분). 크롬 수는 `--workers=N`으로 정해요.

## 스타일: 영상 전체가 하나의 RobinOS 세션

ITCS Connect 광고(가운데 제목이 흐림에서 나타나고, 액자 속 스크린샷에 카메라가 다가가는 방식)와 겹치지 않게, RobinOS에만 있는 것으로 만들었어요(2026-10-12 Robin: "RobinOS만의 완전 새로운 모션그래픽 스타일로").

- **무대가 RobinOS 데스크톱이에요.** 바와 배경을 실제 셸의 1.6배로 그려요. 바의 작업 공간 숫자(1~5)가 영상의 장이고, 장이 바뀔 때 Hyprland처럼 작업 공간이 옆으로 밀려요(slidefade 12%).
- **움직임은 RobinOS 자체의 애니메이션 값이에요(`desktop/hypr/robinos.lua`).** 창은 92%에서 "easy" 스프링(질량 1, 강성 238.1, 감쇠 24.2)으로 튀어나오고, 닫힐 때는 선형 0.14초예요. 레이어(런처, 패널)는 easeOutQuint 페이드예요. 창은 dwindle 방식으로 바둑판처럼 나뉘고, 간격(10·4px), 모서리(12px), 테두리(1px, 활성 0.22·비활성 0.08)도 실제 값의 1.6배예요.
- **글은 아래쪽 프롬프트에 쳐져요.** 제목 대신 빨간 `>` 뒤에 한 글자씩(32분음표마다) 타자가 쳐지고, 단축키는 화면 녹화 프로그램처럼 오른쪽에 키로 보여요.
- **로고도 프롬프트예요.** 빨간 `>`와 커서가 깜빡이다가 울새가 커서에 내려앉고, 그 뒤에 `RobinOS`가 쳐져요. Enter를 누르면 실제 부팅 메뉴 → 로그인(비밀번호 입력) → 바탕 화면으로 이어져요.

## 음악

곡은 Robin이 고른 파일을 `music/track.mp3`에 두고 쓰고, git에는 올리지 않아요(`.gitignore`). 쓰는 구간과 길이는 `cues.js`의 `MUSIC`에 있어요(11초 근처부터, "11초부터 하이라이트"). 박자는 2026-10-12에 `beats.mjs`로 잰 값이에요: 114.75BPM, 10.937초가 한 박, 그 두 박 뒤가 마디의 시작, 16.17초가 드롭, 30.8초와 47.5초가 한 마디씩 쉬는 곳이에요. 다른 곡으로 바꾸면 똑같이 재서 `BPM`, `MUSIC.start`, `SONG`을 맞추고 장면 박 번호를 옮겨요.

```bash
ffmpeg -i music/track.mp3 -map 0:a -ac 1 -ar 22050 -c:a pcm_s16le out/track.wav
node beats.mjs out/track.wav 8 54    # 템포 후보, 박 위치, 마디마다의 세기(드롭과 쉬는 마디가 보여요)
```

**저작권**: 상업 음원은 허락 없이 공개하면 안 돼요. 유튜브는 음소거·수익 이전·차단이 될 수 있고, 저장소에는 음원을 넣지 않아요. 공개할 판은 사용 허락을 받은 곡이나 저작권 걱정 없는 곡으로 다시 녹화해요. 파일이 없으면 `music.mjs`가 같은 박자의 클릭 트랙으로 대신해서 박자 확인은 할 수 있어요.

타자(글자마다 키 소리), Enter, 창이 열리는 소리, 재부팅 때 음악이 끊기는 것과 삐 소리는 `music.mjs`가 코드로 만들어 곡 위에 얹어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `cues.js` | **시간표.** 박자, 장면 시각, 사건 시각, 타자, Enter, 키 표시, 음악 구간. 화면과 소리가 둘 다 이 숫자를 읽어요 |
| `index.html`, `style.css` | 장면의 생김새. 색은 `desktop/shell/Theme.qml`(zinc), 간격·모서리·테두리는 `robinos.lua` |
| `main.js` | 움직임(GSAP 타임라인 하나), 타자와 커서, 창 안의 화면이 창 크기를 따라가는 것 |
| `music.mjs` | 곡 자르기, 타자·창 소리 얹기 → `out/audio.wav` |
| `beats.mjs` | 곡의 템포, 박 위치, 마디마다의 세기 재기 |
| `render.mjs` | 헤드리스 크롬 → 프레임마다 `__video.seek(t)` → 찍기 → ffmpeg |
| `server.mjs`, `preview.mjs`, `fonts.mjs` | 127.0.0.1 로컬 서버, 미리보기, 글꼴 받기 |
| `assets/` | 실제 화면. 부팅 테스트(`build/boot-test`, 2026-10-12)와 설치 테스트(부팅 메뉴, 로그인, 스냅샷 목록)가 찍은 1600×900 스크린샷이에요. `index.html`의 `data-crop`(x, y, 너비, 높이)으로 필요한 부분만 잘라 써요 |

## 지킨 것

- **실제로 있는 기능과 명령만** 넣어요. 화면은 모두 테스트가 찍은 실제 스크린샷이고, 터미널 문구는 `robinos-hints.sh`의 실제 출력이에요. 실제로 없는 출력은 지어내지 않아요(그래서 `sudo robinctl update` 뒤 출력 대신 재부팅으로 넘어가요).
- **보안은 앞세우지 않아요**(2026-10-12 Robin: "보안은 강조하지마"). 부팅 메뉴의 "Security Learning Workstation"과 안내 줄, 로그인 화면 아래의 보안 학습 문구, 런처의 보안 랩 항목은 잘라 내요. 제품 문구를 고치면(T-151) 스크린샷을 새로 찍어 바꿔요.
- 구호는 쓰지 않아요. 화면이 말하게 해요.

## 함정

- **CSS transition/animation은 쓰지 않아요.** 녹화는 타임라인을 프레임마다 멈춰 놓고 찍어서, CSS가 혼자 움직이면 프레임마다 달라져요. 타자, 커서 깜빡임은 `main.js`의 `ambient(t)`가 t만 보고 계산해요.
- **장면 안의 요소는 `visibility`가 아니라 `autoAlpha`로 켜고 꺼요.** 자식에 `visibility: visible`을 주면 부모 장면을 숨겨도 그 자식은 보여요(첫 판에서 부팅 화면이 끝 로고를 덮었어요).
- **`file://`로 열면 안 돼요.** 크롬이 ES 모듈과 글꼴을 막아요. 그래서 로컬 서버를 띄워요.
- 로그인 화면의 비밀번호 칸과 런처 검색 칸의 안내 글자는, 스크린샷에서 그 칸의 색을 읽어(`sampleColors`) 같은 색으로 덮고 그 위에 쳐요.
- **Node 24의 `fs.rmSync`는 한글이 든 절대 경로에서 프로그램째 죽어요**(윈도우, 0xC0000409, 오류 메시지 없음, 2026-10-12 Node 24.13). 이 저장소는 `바탕화면` 아래라서 파일은 `fs.unlinkSync`로 지워요. 영문인 임시 폴더(`os.tmpdir()`)에서는 `rmSync`도 괜찮아요.
- 크롬을 닫을 때는 DevTools 연결(WebSocket)을 먼저 닫고 끝난 뒤에 크롬을 꺼요.
- 결과물(`out/`), 글꼴(`fonts/`), 음악(`music/`)은 git에 올리지 않아요.
