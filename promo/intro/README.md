# RobinOS 소개 영상

RobinOS를 41초 동안 보여 주는 모션그래픽 영상이에요. 1920×1080, 60fps에 소리가 들어 있어요. 2026-10-12에 만들었어요.

영상 편집 프로그램 없이 **웹 페이지(HTML/CSS + GSAP)로 짜고, 헤드리스 크롬으로 한 프레임씩 찍어 mp4로 묶어요.** 실시간 화면 녹화가 아니라서 PC가 느려도 프레임이 빠지지 않아요. 음악도 코드로 만들어요.

```bash
cd promo/intro
npm install            # gsap 하나
npm run fonts          # Geist, Pretendard 받기 (scripts/fetch-fonts.sh와 같은 릴리스·체크섬)
npm run preview        # 브라우저 미리보기: 클릭·Space = 재생/멈춤, ←/→ 2초 이동, 주소 끝에 ?t=12 → 12초부터
npm run render         # out/robinos-intro.mp4 (60fps, 1~2분)
npm run render:draft   # out/robinos-intro-draft.mp4 (30fps, 빨리 확인할 때)
node render.mjs --stills=4.5,12,27   # 그 시각만 out/stills/*.png로 찍기
```

필요한 것: Node 18 이상, 크롬(다른 곳에 있으면 `CHROME=<경로>`), libx264와 aac가 들어 있는 ffmpeg(PATH에 두거나 `FFMPEG=<경로>`). Remotion이 받아 둔 ffmpeg는 DLL이 `../lib`에 있는데, `render.mjs`가 그 폴더도 PATH에 넣어 줘요.

**녹화 속도**: 프레임마다 시각을 정해 멈춰 놓고 찍는 방식이라 구간을 나눠 동시에 찍어도 결과가 같아요. `render.mjs`는 크롬 여러 개(기본: CPU 스레드의 3분의 1, 최대 6개)가 구간을 하나씩 맡아 조각 mp4를 만들고, ffmpeg가 다시 압축하지 않고 이어 붙여요. 프레임은 JPEG 95로 찍고(`--png`면 무손실), x264는 `medium`이에요(`--preset=slow`). 2026-10-12 robin PC(16스레드)에서 크롬 5개로 41초 영상이 약 70초 걸렸어요. 크롬 수는 `--workers=N`으로 정해요.

## 스타일: 키노트처럼

2026-10-12 Robin: "PPT 슬라이드 같아", "애플 느낌의 모션그래픽". 그래서 이렇게 만들었어요.

- **한 번에 한 문장.** 검은 바탕에 큰 글자 하나가 말해요. 단어는 흐림에서 떠올라 한 박에 하나씩 자리를 잡고(긴 착지 곡선 `0.16, 1, 0.3, 1`), 강조할 말은 RobinOS 빨강에서 주황으로 가는 그라데이션이에요.
- **실제 화면이 공중에 떠 있어요.** 스크린샷은 모두 테스트가 찍은 실제 RobinOS 화면이고, 깊이(원근)를 두고 기울어진 채 들어와 바로 서요. 앞의 패널은 뒤로 물러나 쌓여요.
- **멈춘 장면이 없어요.** 뒤의 부드러운 빛 세 개가 천천히 떠다니고 킥마다 살짝 숨을 쉬어요. 장면마다 카메라가 조금씩 다가가고, 장면이 바뀔 때는 앞의 것이 카메라 쪽으로 흐려지며 빠져요.
- **박자에 맞춰요.** 장면, 단어, 키 누름, Enter가 모두 `cues.js`의 박 번호에 있어요. 쉬는 마디에 다크에서 라이트로 바뀌고, 두 번째 드롭에 "되돌리기"가 시작해요.
- 창이 튀어나오는 곳에는 RobinOS 자체의 창 스프링(`desktop/hypr/robinos.lua`의 "easy": 질량 1, 강성 238.1, 감쇠 24.2)을 써요.

## 음악

`music.mjs`가 곡을 처음부터 끝까지 코드로 합성해요(2026-10-12 Robin: "노래 그냥 너가 만들고"). 남의 음원이 없어서 영상을 어디에 올려도 저작권 걱정이 없어요.

- 일렉트로닉 펑크, 116BPM, D단조. 화음은 Dm9 – B♭maj9 – Gm9 – A7sus4, 한 마디씩이에요.
- 킥(사인 스윕), 클랩, 16분 하이햇(그루브를 위해 홀수 칸을 12ms 늦게), 셰이커, 엔벨로프 필터를 건 신스 베이스(옥타브 점프), 로즈 같은 FM 건반(엇박 스탭), 두 번째 드롭의 플럭 훅, 점8분 핑퐁 딜레이, 킥에 맞춘 사이드체인.
- 구간은 `cues.js`의 `SONG`이에요: 도입(건반과 라이저) → 8박 드롭 → 48박 쉬는 마디(라이저) → 52박 두 번째 드롭 → 72박 마지막 한 방과 울림.
- 타자(글자마다 키 소리), 키캡, Enter, 장면이 바뀔 때의 바람 소리도 같은 파일이 만들어 곡 위에 얹어요.

박자를 바꾸면 `cues.js`의 `BPM`만 고치면 돼요. 화면과 소리가 같은 박 번호를 읽어요. 만든 소리를 재 보려면 이렇게 해요(`beats.mjs`는 모노 WAV를 읽어요).

```bash
ffmpeg -i out/audio.wav -ac 1 -ar 22050 -c:a pcm_s16le out/mono.wav
node beats.mjs out/mono.wav 0 42    # 템포, 박 위치, 마디마다의 세기(드롭과 쉬는 마디가 보여요)
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `cues.js` | **시간표.** 박자, 곡 구간, 장면, 타자, 키 누름, Enter, 바람 소리. 화면과 소리가 둘 다 이 숫자를 읽어요 |
| `index.html`, `style.css` | 장면의 생김새. 색은 `desktop/shell/Theme.qml`(zinc)과 RobinOS 빨강 |
| `main.js` | 움직임(GSAP 타임라인 하나), 단어 나누기, 타자·커서·숫자 세기·빛을 t로 계산하기 |
| `music.mjs` | 곡 합성과 효과음 → `out/audio.wav` |
| `beats.mjs` | WAV의 템포, 박 위치, 마디마다의 세기 재기 |
| `render.mjs` | 헤드리스 크롬 → 프레임마다 `__video.seek(t)` → 찍기 → ffmpeg |
| `server.mjs`, `preview.mjs`, `fonts.mjs` | 127.0.0.1 로컬 서버, 미리보기, 글꼴 받기 |
| `assets/` | 실제 화면. 부팅 테스트(`build/boot-test`, 2026-10-12)와 설치 테스트(부팅 메뉴, 로그인, 스냅샷 목록)가 찍은 1600×900 스크린샷이에요. `index.html`의 `data-crop`(x, y, 너비, 높이)으로 필요한 부분만 잘라 써요 |

## 지킨 것

- **실제로 있는 기능과 명령만** 넣어요. 화면은 모두 테스트가 찍은 실제 스크린샷이고, 터미널 문구는 `robinos-hints.sh`의 실제 출력이에요. 스냅샷 줄의 세 점(설치, 업데이트 전, 업데이트 후)도 부팅 메뉴의 실제 목록(single, pre, post)과 같아요.
- **보안은 앞세우지 않아요**(2026-10-12 Robin: "보안은 강조하지마"). 부팅 메뉴의 "Security Learning Workstation"과 안내 줄은 그 자리의 배경색으로 덮고, 런처는 보안 랩 항목 전에서 잘라요. 제품 문구를 고치면(T-151) 스크린샷을 새로 찍어 바꿔요.

## 함정

- **CSS transition/animation은 쓰지 않아요.** 녹화는 타임라인을 프레임마다 멈춰 놓고 찍어서, CSS가 혼자 움직이면 프레임마다 달라져요. 타자, 커서 깜빡임, 숫자 세기, 떠다니는 빛은 `main.js`의 `ambient(t)`가 t만 보고 계산해요.
- **장면 안의 요소는 `visibility`가 아니라 `autoAlpha`로 켜고 꺼요.** 자식에 `visibility: visible`을 주면 부모 장면을 숨겨도 그 자식은 보여요.
- **선을 그리는 SVG는 그리기 전까지 숨겨요.** `stroke-dasharray`로 길이 0인 선을 남겨도 둥근 끝(`round` cap)은 점으로 찍혀요.
- **`file://`로 열면 안 돼요.** 크롬이 ES 모듈과 글꼴을 막아요. 그래서 로컬 서버를 띄워요.
- 로그인 화면의 비밀번호 칸과 런처 검색 칸의 안내 글자는, 스크린샷에서 그 칸의 색을 읽어(`sample`) 같은 색으로 덮고 그 위에 쳐요.
- **Node 24의 `fs.rmSync`는 한글이 든 절대 경로에서 프로그램째 죽어요**(윈도우, 0xC0000409, 오류 메시지 없음, 2026-10-12 Node 24.13). 이 저장소는 `바탕화면` 아래라서 파일은 `fs.unlinkSync`로 지워요. 영문인 임시 폴더(`os.tmpdir()`)에서는 `rmSync`도 괜찮아요.
- 크롬을 닫을 때는 DevTools 연결(WebSocket)을 먼저 닫고 끝난 뒤에 크롬을 꺼요.
- 결과물(`out/`), 글꼴(`fonts/`)은 git에 올리지 않아요.
