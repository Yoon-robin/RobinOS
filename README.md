# 🐦 RobinOS

당신만의 데스크톱 OS 경험. macOS 느낌의 깔끔한 UI와 부드러운 애니메이션을
목표로, **React + motion**으로 데스크톱 셸(메뉴바·독·창)을 직접 만든 프로젝트예요.

> 지금 단계는 "**경험과 디자인**"을 만드는 단계입니다. 화면 속 데스크톱을
> 먼저 완성하고, 나중에 원하면 리눅스 위에 풀스크린으로 올려 **진짜 부팅되는
> OS**로 발전시킬 수 있어요.

## 실행 방법

```bash
npm install      # 처음 한 번만
npm run dev      # 개발 서버 시작
```

그다음 브라우저에서 **http://localhost:5173** 을 열면 RobinOS가 부팅됩니다.

## 지금 들어있는 것 (v0.1)

- 🖥️ **부팅 화면** — 로고가 나타나고 진행 바가 채워진 뒤 데스크톱으로 전환
- 📊 **메뉴바** — 반투명 블러, 현재 앱 이름, 실시간 시계
- 🚀 **독(Dock)** — 마우스를 올리면 아이콘이 커지는 macOS식 확대 효과
- 🪟 **창(Window)** — 신호등 버튼, 드래그 이동, 열고 닫을 때 스프링 애니메이션

## 폴더 구조

```
src/
  App.tsx              앱 전체 상태(부팅·창 관리)
  main.tsx             진입점
  index.css            전역 스타일(macOS 느낌의 CSS)
  data/apps.ts         독에 들어가는 앱 목록
  components/
    BootScreen.tsx     부팅 화면
    MenuBar.tsx        상단 메뉴바
    Dock.tsx           하단 독 + 확대 효과
    Window.tsx         드래그 가능한 창
```
