윈도우에서 하던 그대로

Alt+Tab으로 창을 바꾸고 Win+D로 바탕 화면을 봐요. 앱은 윈도우에서 부르던 이름으로 찾으면 돼요.

윈도우 이름으로 찾기

"메모장"을 찾으면 텍스트 편집기가 나오고, 옆에 "윈도우의 메모장에 해당해요"라고 적혀 있어요.

단축키

손에 익은 키가 대부분 돼요. 전체 목록은 Win+F1로 열어요.

.exe를 열면

바로 실행하지 않고, 대신 쓸 수 있는 리눅스 앱을 보여 줘요.

작업 보기

Win+Tab으로 열린 창과 작업 공간을 한 번에 봐요.

막히는 곳에서 배워요

아래 칸에 윈도우 명령을 쳐 보세요. RobinOS 터미널이 하는 그대로, 리눅스 명령과 연습할 미션이 나와요.

robin@robinos: ~
robin@robinos ~ >

Enter를 누르면 답이 나와요. 실제로 실행되지는 않아요.

robin@robinos ~ > ipconfig
ipconfig 명령은 윈도우용이에요. 리눅스에서는
  ip a  IP 주소와 네트워크 장치를 보여 줘요

망가지면 되돌려요

아래는 설치 테스트에서 찍은 실제 부팅 메뉴예요.

  1. 업데이트 전에 저절로 스냅샷

    프로그램을 설치하거나 업데이트하면 그 직전(pre)과 직후(post)가 목록에 남아요.

  2. 부팅 메뉴에서 고르기

    켜지지 않거나 이상하면 부팅 메뉴의 "RobinOS snapshots"로 들어가요.

  3. 그 상태로 켜서 계속 쓰기

    고른 스냅샷의 커널로 켜져요. 그다음 알림에서 "이 상태로 되돌리기"를 누르면 그 상태로 계속 써요.

스냅샷은 시스템만 되돌려요. 사진과 문서는 백업 앱으로 USB 디스크에 따로 남겨요.

처음부터 한국어로

켜자마자 한/영 키로 한글을 쓰고, 메뉴와 안내도 모두 한국어예요.

USB로 켜기만 해도

  • 한글 입력 한/영 키와 오른쪽 Alt
  • 화면 녹화 Win+Alt+R
  • 손쉬운 사용 화면 확대, 큰 글씨, 움직임 줄이기

설치하면

  • 앱 스토어 Flathub의 앱
  • 오피스 LibreOffice
  • 프린터와 스캐너 대부분 드라이버 없이
  • 방화벽 처음부터 켜져 있어요
  • 백업 개인 파일을 USB 디스크에

설치하기 전에 먼저 켜 봐요

USB로 켜면 지금 쓰는 컴퓨터를 건드리지 않고 써 볼 수 있어요.

  1. ISO 내려받기

    GitHub 릴리스에서 받아요. 파일이 맞는지는 체크섬과 서명으로 확인해요.

  2. USB로 켜기

    Rufus나 Ventoy로 USB에 담아요. USB가 없으면 윈도우 디스크의 빈 파티션에서도 켤 수 있어요.

  3. 써 보고 설치하기

    마음에 들면 독의 "RobinOS 설치"를 눌러요. 윈도우 옆에도 설치돼요.

필요한 것

  • UEFI로 켜는 PC
  • 보안 부팅 끄기
  • 디스크 40GB 이상

지금은 미리 보기예요

코드가 바뀔 때마다 가상 머신에서 켜고 설치까지 해 보지만, 실제 PC에서는 아직 한 번도 못 해 봤어요. 중요한 자료가 있는 컴퓨터에는 설치하지 마세요.

써 보다 문제가 보이면 GitHub 이슈로 알려 주세요.
