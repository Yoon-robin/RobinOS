# RobinOS v0.2 프리뷰

RobinOS는 윈도우에서 넘어와 매일 쓰면서 리눅스와 보안을 배우는 OS예요. v0.2는 매일 쓰는 데 필요한 앱과 윈도우에서 쓰던 습관을 더 채우고, 학습 미션을 25개로, 그리고 입문 CTF를 더했어요. v0.1의 내용은 [release-notes-v0.1.md](release-notes-v0.1.md)에 있어요.

## 새로 들어간 것

### 매일 쓰기

- **오피스, 앱 스토어, 프린터, 디스크 관리**: 설치한 시스템에 LibreOffice(한국어), GNOME 소프트웨어(Flathub 앱 설치), 프린터 설정(CUPS), GNOME 디스크가 들어가요. 런처에서 "워드", "엑셀", "Microsoft Store", "장치 및 프린터", "디스크 관리"처럼 윈도우 이름으로 찾아요.
- **NVIDIA 그래픽 카드**: 설치기가 GTX 16, RTX 20 이후 카드를 찾으면 NVIDIA 드라이버(`nvidia-open`)를 설치해요. `robinctl doctor`가 드라이버가 떠 있는지 알려 줘요.
- **업데이트 알림**: 업데이트가 있으면 바에 표시되고, 빠른 설정의 "업데이트 N개" 단추로 스냅샷과 함께 설치해요. 앱 스토어 앱도 `sudo robinctl update`가 함께 올려요.
- **전원 모드**: 빠른 설정에서 절전, 균형, 최고 성능을 골라요.
- **창 제목 표시줄**: Qt 앱(Wireshark, 설치기 등)에도 최대화·닫기 단추가 있는 제목 표시줄이 생겼어요.
- **Firefox**: 원격 측정과 실험 기능을 기본으로 꺼 뒀어요.

### 윈도우에서 쓰던 그대로

- `Win+V` 클립보드 기록(최근 50개, 로그아웃하면 지워지고 비밀번호 관리자가 숨긴 복사는 남기지 않아요)
- `Win+Shift+S` 화면 캡처, 바의 시계를 누르면 달력(`Win+Alt+D`)
- 윈도우 명령 힌트 40개쯤(`calc`, `eventvwr`, `services.msc`, `diskmgmt.msc` ...)
- 독에는 설치된 앱만 고정돼요(설치 안 된 Wireshark가 눌러도 반응 없던 문제를 고쳤어요)

### 배우기

- **학습 미션 25개**: 리눅스, 네트워크에 더해 포렌식 기초(파일 종류, 해시, 사진 정보, 숨은 파일, 로그), 리버싱 기초(`readelf`, `strings`, `ltrace`, `strace`, `objdump`), 웹 기초(내 컴퓨터에서만 열리는 연습 서버로 `curl`, 헤더, robots.txt, 쿠키, 리다이렉트). 런처의 "학습 미션"에 진행도가 보여요.
- **입문 CTF 5문제**: `robinctl ctf`. 미션에서 배운 기술을 섞어 플래그를 찾아요. 푸는 요령과 다음 연습장은 [ctf.md](ctf.md)에 있어요.

## v0.1에서 올라오려면

v0.1로 설치한 시스템은 `sudo robinctl update`로 시스템 패키지만 올라가요. RobinOS 자체 파일(셸, `robinctl`, 미션)을 새 버전으로 올리는 길은 아직 없어서, v0.2의 기능을 쓰려면 새 ISO로 다시 설치해야 해요. `/home`의 파일은 미리 백업하세요.

## 이렇게 확인했어요

이 버전의 ISO로 VM에서 아래를 통과했어요. 방법은 [testing.md](testing.md)에 있어요.

- 부팅 테스트 33장면: 환영 마법사, 런처(윈도우 이름, 학습 진행도, 입문 CTF), 설치기, 빠른 설정(전원 모드), 달력, 터미널 힌트, 최소화와 바탕 화면 보기, 화면 캡처, 클립보드 기록, 셸 다시 띄우기, 라이트 모드, 잠금 화면
- 설치 테스트 세 가지(설치기로 디스크 전체, 윈도우 옆, archinstall)와 설치한 시스템의 스냅샷 되돌리기, 인쇄 서비스, 오피스, 앱 스토어, 업데이트 확인, 열린 포트
- `robinctl`과 설치기 자동 테스트: 미션 25개와 CTF 5문제를 실제로 풀어 보는 테스트 포함

## 알려진 한계

- **실제 PC와 실제 윈도우 옆 설치는 아직 확인 전이에요.** VM에서만 검증했어요. 특히 NVIDIA 드라이버는 실제 카드에서 확인하지 못했어요. 중요한 자료는 꼭 백업하세요.
- 창 제목 표시줄에는 최소화 단추가 없어요. Hyprland가 아직 앱의 최소화 요청을 처리하지 않아서, 최소화는 독에서 해요. 터미널(foot)에는 제목 표시줄이 없어요.
- 화면 읽기 프로그램(Orca)은 넣지 않았어요. Hyprland가 Orca의 키 입력 방식을 아직 지원하지 않아요.
- 윈도우 전용 보안 프로그램을 요구하는 은행·공공기관 사이트는 리눅스에서 안 될 수 있어요.
- 설치기에서 언어와 시간대 고르기, 디스크 암호화는 아직 없어요.
- ISO에 서명이 아직 없어요. 내려받은 뒤 `SHA256SUMS`로 확인하세요.
- 라이브 ISO에는 가벼운 보안 도구만 있고, 오피스·앱 스토어·프린터·디스크 관리는 설치한 시스템에만 들어가요(깃허브 첨부 파일 한도 2GiB 때문이에요).

## 윤리

RobinOS의 보안 도구, 랩, CTF는 내 컴퓨터, 직접 소유한 시스템, 허가받은 대상에서만 써요. 자세한 기준은 [ethics.md](ethics.md)에 있어요.
