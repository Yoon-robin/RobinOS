# RobinOS v0.2 프리뷰

RobinOS는 윈도우에서 넘어와 매일 쓰면서 리눅스와 보안을 배우는 OS예요. v0.2는 매일 쓰는 데 필요한 앱과 윈도우에서 쓰던 습관을 더 채우고, 학습 미션을 45개로 늘려 학습 센터에 모았고, 입문 CTF를 더했어요. 새 울새 로고와 RobinOS 이름이 시스템 곳곳에 들어갔어요. v0.1의 내용은 [release-notes-v0.1.md](release-notes-v0.1.md)에 있어요.

## 새로 들어간 것

### 매일 쓰기

- **오피스, 앱 스토어, 프린터, 디스크 관리, 동영상·음악**: 설치한 시스템에 LibreOffice(한국어), GNOME 소프트웨어(Flathub 앱 설치), 프린터 설정(CUPS), GNOME 디스크, 동영상 재생 앱과 오디오 재생기(MP4 포함)가 들어가요. 런처에서 "워드", "엑셀", "Microsoft Store", "장치 및 프린터", "디스크 관리", "미디어 플레이어"처럼 윈도우 이름으로 찾아요. 파일을 두 번 누르면 알맞은 앱으로 열려요.
- **게임**: 런처에서 "Steam 설치하기"를 고르면 앱 스토어에서 Steam(Flathub)을 받아요.
- **NVIDIA 그래픽 카드**: 설치기가 GTX 16, RTX 20 이후 카드를 찾으면 NVIDIA 드라이버(`nvidia-open`)를 설치해요. `robinctl doctor`가 드라이버가 떠 있는지 알려 줘요.
- **업데이트 알림**: 업데이트가 있으면 바에 표시되고, 빠른 설정의 "업데이트 N개" 단추로 스냅샷과 함께 설치해요. 앱 스토어 앱도 `sudo robinctl update`가 함께 올려요.
- **전원 모드와 배터리**: 빠른 설정에서 절전, 균형, 최고 성능을 골라요. 노트북은 배터리가 10%, 5% 남으면 알려 줘요.
- **창 제목 표시줄**: Qt 앱(Wireshark, 설치기 등)에도 최대화·닫기 단추가 있는 제목 표시줄이 생겼어요.
- **Firefox**: 원격 측정과 실험 기능을 기본으로 꺼 뒀어요.
- **보안 점검**: `robinctl audit`(런처의 "Windows 보안")이 윈도우 보안처럼 열린 포트, 원격 접속, 홈 폴더와 SSH 열쇠 권한, 스냅샷, 방화벽, 디스크 암호화를 한눈에 보여 줘요.
- **앱 제거**: 런처에서 앱을 고르고 `Shift+Delete`(`robinctl app remove`). 터미널, 파일, 셸처럼 RobinOS에 꼭 필요한 앱은 지우지 않아요.

### 윈도우에서 쓰던 그대로

- `Win+V` 클립보드 기록(최근 50개, 로그아웃하면 지워지고 비밀번호 관리자가 숨긴 복사는 남기지 않아요)
- `Win+Shift+S` 화면 캡처(알림을 누르면 사진, "폴더 열기" 단추로 폴더), 바의 시계를 누르면 달력(`Win+Alt+D`)
- `Ctrl+Shift+Esc` 작업 관리자, `Win+I` 설정(빠른 설정), `Win+R` 실행(런처)
- 빠른 설정 타일의 화살표로 Wi-Fi 목록(비밀번호 입력 포함)과 블루투스 장치 목록, 음량 막대의 화살표로 출력 장치·마이크·앱별 음량(볼륨 믹서), `Win+N` 알림 센터(지난 알림을 누르면 그 내용이 열려요)
- `Win+.` 이모지: 한국어·영어로 찾아 Enter를 누르면 원래 창에 들어가요
- 독 아이콘에 마우스를 올리면 창 미리보기, 오른쪽 클릭하면 작업 표시줄처럼 메뉴(새 창, 독에 고정·고정 풀기, 창 닫기)
- 바탕 화면 오른쪽 클릭 메뉴: 터미널 열기, 파일 탐색기, 배경화면 바꾸기, 디스플레이 설정, 단축키 보기
- `Win+X` 빠른 메뉴(런처 단추 오른쪽 클릭도): 작업 관리자, 디스크 관리, 보안 점검, 이벤트 뷰어, 종료
- `Win+Tab` 작업 보기: 모든 작업 공간의 창을 미리보기로 보고 골라요
- `Alt+Tab`: Alt를 누르고 있는 동안 창 미리보기가 최근에 쓴 순서로 나오고, 놓으면 그 창으로 가요
- `Win+←/→` 창을 화면 반쪽에, `Win+↑` 최대화, `Win+↓` 되돌리기·최소화, `Win+Ctrl+←/→` 작업 공간 바꾸기, `Win+Ctrl+D`·`Win+Ctrl+F4` 작업 공간 만들기·닫기
- 바의 트레이 아이콘(Steam, Discord 등): 누르면 열리고 오른쪽 버튼은 메뉴
- 런처에서 파일 이름 찾기와 최근에 연 파일, 수식 계산(`12*3`), 웹 검색(시작 메뉴처럼)
- 런처에서 윈도우 관리 도구 이름(이벤트 뷰어, 서비스, 작업 스케줄러, 장치 관리자, 시스템 정보)을 찾으면 같은 일을 하는 리눅스 명령(`journalctl`, `systemctl`, `lspci` 등)을 터미널에서 보여 줘요
- 윈도우 명령 힌트 70개 넘게(`calc`, `start`, `clip`, `powercfg`, `eventvwr`, `services.msc`, `diskmgmt.msc`, `ncpa.cpl` ...)
- 독에는 설치된 앱만 고정돼요(설치 안 된 Wireshark가 눌러도 반응 없던 문제를 고쳤어요)

### RobinOS다운 모습

- **새 로고**: 터미널 프롬프트의 커서 위에 앉은 하얀 울새. 바, 런처, 로그인 화면, 부팅 메뉴, 터미널(fastfetch)에 들어갔어요.
- **터미널 프롬프트**: `robin@robinos ~ >`. 명령이 실패하면 `>` 앞에 종료 코드가 빨갛게 나와요.
- **시스템 이름**: fastfetch, `hostnamectl`, `robinctl doctor`가 "RobinOS"로 보여 줘요(Arch Linux 기반).
- 라이브 ISO의 시계가 한국 시간이에요.

### 배우기

- **학습 미션 45개**: 리눅스, 네트워크에 더해 포렌식 기초(파일 종류, 해시, 사진 정보, 숨은 파일, 로그), 리버싱 기초(`readelf`, `strings`, `ltrace`, `strace`, `objdump`), 웹 기초(내 컴퓨터에서만 열리는 연습 서버로 `curl`, 헤더, robots.txt, 쿠키, 리다이렉트), 셸 기초(환경 변수, PATH, 별명, 스크립트 인자, 종료 코드), 시스템 기초(프로세스, 디스크, 서비스, 시스템 기록), 보안 기초(사용자와 그룹, 파일 권한, SSH 열쇠, 내려받은 파일 검사, 암호화), 텍스트 다루기(웹 서버 기록을 `grep -c`, `sort | uniq -c`, `awk`로 분석하고, `sed`로 비밀번호 가리기, `diff`로 몰래 생긴 계정 찾기).
- **학습 센터**: 런처의 "학습 미션"이나 환영 마법사에서 열려요. 진행도, 다음 미션, 미션 45개와 입문 CTF가 한 창에 있고, 미션을 고르면 터미널에서 열려요. 터미널에서 미션을 통과하면 체크가 바로 바뀌어요.
- **입문 CTF 10문제**: `robinctl ctf`. 미션에서 배운 기술을 섞어 플래그를 찾아요. 푸는 요령과 다음 연습장은 [ctf.md](ctf.md)에 있어요.

## v0.1에서 올라오려면

v0.1로 설치한 시스템은 `sudo robinctl update`로 시스템 패키지만 올라가요. RobinOS 자체 파일(셸, `robinctl`, 미션)을 새 버전으로 올리는 길은 아직 없어서, v0.2의 기능을 쓰려면 새 ISO로 다시 설치해야 해요. `/home`의 파일은 미리 백업하세요.

## 이렇게 확인했어요

이 버전의 ISO로 VM에서 아래를 통과했어요. 방법은 [testing.md](testing.md)에 있어요.

- 부팅 테스트 79장면: 환영 마법사와 학습 센터(CTF 목록까지), 바탕 화면의 Alt+F4 전원 메뉴, 런처(윈도우 이름, 학습 진행도, 입문 CTF, 파일 찾기와 최근 파일, 계산과 웹 검색, 이모지, 앱 제거 안내, 이벤트 뷰어), 보안 점검, 설치기, 빠른 설정(전원 모드, 화면 배율, 야간 모드, 키보드 조작), Wi-Fi·블루투스 연결 창, 소리 창, 달력(공휴일), 단축키 보기, 터미널(프롬프트, 힌트, fastfetch 로고), 최소화와 Win+방향키 창 붙이기, 작업 공간 바꾸기·만들기·닫기, 바탕 화면 보기와 오른쪽 클릭 메뉴, 화면 캡처와 알림, 클립보드 기록(이미지 포함), 알림 센터(지난 스크린샷 알림을 눌러 사진 열기), 트레이 아이콘, 바의 휠 음량, 독 미리보기와 오른쪽 클릭 메뉴로 고정, Alt+Tab, Win+Tab 작업 보기, 배경화면 바꾸기와 되돌리기, 셸 다시 띄우기, 라이트 모드, 잠금 화면
- 설치 테스트 세 가지(설치기로 디스크 전체, 윈도우 옆, archinstall)와 설치한 시스템의 스냅샷 되돌리기, 인쇄 서비스, 오피스, 앱 스토어, 동영상·음악과 기본 앱, 업데이트 확인, 열린 포트(sshd는 꺼짐, 라이브 ISO의 LLMNR도 꺼짐), 미션과 런처에 필요한 명령(ssh-keygen, gpg, lspci, lsusb), 업그레이드 뒤에도 남는 RobinOS 이름
- `robinctl`과 설치기 자동 테스트: 미션 45개와 CTF 10문제를 실제로 풀어 보는 테스트 포함

## 알려진 한계

- **실제 PC와 실제 윈도우 옆 설치는 아직 확인 전이에요.** VM에서만 검증했어요. 특히 NVIDIA 드라이버는 실제 카드에서 확인하지 못했어요. 중요한 자료는 꼭 백업하세요.
- 창 제목 표시줄에는 최소화 단추가 없어요. Hyprland가 아직 앱의 최소화 요청을 처리하지 않아서, 최소화는 독에서 해요. 터미널(foot)에는 제목 표시줄이 없어요.
- 화면 읽기 프로그램(Orca)은 넣지 않았어요. Hyprland가 Orca의 키 입력 방식을 아직 지원하지 않아요.
- 윈도우 전용 보안 프로그램을 요구하는 은행·공공기관 사이트는 리눅스에서 안 될 수 있어요.
- 설치기에서 언어와 시간대 고르기, 디스크 암호화는 아직 없어요.
- ISO에 서명이 아직 없어요. 내려받은 뒤 `SHA256SUMS`로 확인하세요.
- 배터리 알림과 Steam 설치는 실제 노트북과 그래픽 카드에서 아직 확인하지 못했어요.
- 라이브 ISO에는 가벼운 보안 도구만 있고, 오피스·앱 스토어·프린터·디스크 관리는 설치한 시스템에만 들어가요(깃허브 첨부 파일 한도 2GiB 때문이에요).

## 윤리

RobinOS의 보안 도구, 랩, CTF는 내 컴퓨터, 직접 소유한 시스템, 허가받은 대상에서만 써요. 자세한 기준은 [ethics.md](ethics.md)에 있어요.
