# RobinOS 비전

RobinOS는 남의 OS에 테마만 입힌 배포판이 아니라, 처음부터 직접 만든 화면과 도구로 이루어진 나만의 OS예요. 매일 쓰는 컴퓨터로 충분하고, 그 위에서 리눅스와 보안도 배울 수 있어요. 확정한 설계와 방향 결정(2026-10-10)은 [design.md](design.md)에 있어요.

## 브랜드 약속

켜는 순간부터 끄는 순간까지 RobinOS예요. 부팅 화면, 로그인, 바탕 화면, 설치, 설정, 업데이트, 복구가 모두 같은 디자인 언어로 이어져요.

## RobinOS를 RobinOS로 만드는 것

### 1. 직접 만든 데스크톱

상단 바, 독, 런처, 빠른 설정, 알림, 창 전환, 환영 마법사, 학습 센터, 설치기를 Quickshell로 직접 그려요(`desktop/shell/`). 색, 간격, 글꼴, 아이콘은 한 곳(`desktop/shell/Theme.qml`)에서 정하고, Firefox나 파일 같은 남의 앱에도 같은 색과 글꼴을 입혀요.

### 2. 자체 시스템 계층

RobinOS에는 자체 명령과, 시스템을 하나로 엮어 주는 연결 코드가 있어요.

```bash
robinctl doctor
robinctl update
robinctl repo
robinctl snapshot rollback 12
robinctl audit
robinctl learn
robinctl lab start web
```

설치기(`robin-install`), 업데이트 저장소(서명한 `robinos` 패키지), 스냅샷 복구도 RobinOS가 직접 맡아요. 그래야 RobinOS가 테마 팩이 아니라 진짜 OS처럼 느껴져요.

### 3. 매일 쓰는 컴퓨터

웹, 문서, 사진, 동영상, 음악, 프린터, 앱 스토어, 게임(Steam)이 처음부터 돼요. 업데이트로 망가져도 부팅 메뉴에서 되돌릴 수 있어요.

### 4. 한국어가 기본

첫 부팅부터 한국어 화면, 한글 입력(오른쪽 Alt), 한글에 맞는 글꼴, 한국어 문서와 안내예요. 말투는 쉬운 해요체예요.

### 5. 쉽게 시작

윈도우에서 와도 헤매지 않게 익숙한 단축키와 이름이 동작해요(`Win+E`, `Alt+Tab`, 런처에서 "제어판" 검색). 이건 입구예요. 그 뒤의 화면은 RobinOS 방식이에요.

### 6. 배울 수 있는 OS

배우고 싶을 때 학습 센터가 리눅스 기초부터 네트워크, 웹 보안, 포렌식, 리버싱까지 미션으로 안내하고 결과를 확인해요. 보안 도구는 처음부터 전부 깔지 않고, 배우는 단계에 맞춰 프로필로 골라 깔아요(`robinctl profile`). 실습은 안전하게 해요.

- 실습 대상은 내 컴퓨터 안의 랩에만(`127.0.0.1`, 컨테이너)
- 학습 도구와 일상 앱을 분리
- 기본 프로필에는 은닉, 지속성 확보, 자격 증명 악용 도구 없음
- 기준은 [ethics.md](ethics.md)

## 기반: Arch Linux

이유:

- Hyprland, Quickshell 같은 데스크톱 부품과 보안·개발 패키지가 최신이에요
- `archiso`로 마음껏 손볼 수 있는 구조예요
- `pacman`으로 RobinOS 자체 저장소를 붙이기 쉬워요
- 다른 배포판의 변형으로 보이지 않아서 RobinOS만의 정체성을 만들기에 잘 맞아요

Kali Linux는 보안 도구 모음의 참고 대상일 뿐 기반이 아니에요. Kali를 기반으로 삼으면 RobinOS는 Kali 리믹스로 보이기 쉬워요.
