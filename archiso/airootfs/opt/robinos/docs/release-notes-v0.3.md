# RobinOS v0.3 프리뷰

RobinOS로 시작하는 첫 리눅스. 윈도우에서 넘어온 사람이 익숙한 이름과 단축키로 시작해서, 쓰는 동안 리눅스 명령을 하나씩 알게 되는 OS예요. v0.3은 화면을 새로 다듬고, 윈도우 습관에서 리눅스로 이어 주는 길(터미널 힌트, 런처, 학습 미션)을 한 줄로 이었어요. 망가졌을 때 되돌리는 과정도 화면에서 할 수 있게 됐어요. v0.2의 내용은 [release-notes-v0.2.md](release-notes-v0.2.md)에 있어요.

소개 페이지: https://yoon-robin.github.io/RobinOS/

## 새로 들어간 것

### 윈도우에서 리눅스로

- **터미널 힌트가 미션으로 이어져요**: `ipconfig`처럼 윈도우 명령을 치면 리눅스 명령과 함께 "직접 해 보기: 학습 미션 6 → robinctl learn show 6"이 나와요(윈도우 명령 38개).
- **런처의 윈도우 이름에 리눅스 쪽도**: "작업 관리자", "서비스", "이벤트 뷰어" 등을 찾으면 앱 옆에 "터미널: ps aux, top" 같은 명령과 그 개념의 학습 미션이 함께 나와요.
- **.exe를 열면 안내 창**: 윈도우 프로그램은 실행하지 않고, 잘 알려진 17가지(카카오톡, Chrome, 반디집, 한컴오피스 등)는 대신 쓸 앱이나 앱 스토어의 리눅스판을 보여 줘요. 모르는 파일이면 Bottles를 안내해요.
- **화면 녹화**: `Win+Alt+R`로 시작하고 한 번 더 누르면 멈춰요. 녹화 중에는 바에 빨간 점이 떠요.

### 화면

- **새 재질과 움직임**: 바, 독, 패널이 반투명 유리처럼 뒤를 비추고, 런처는 Spotlight처럼, 빠른 설정은 제어 센터처럼 바뀌었어요. 그래픽 가속이 없는 PC나 "투명도 줄이기"를 켜면 불투명해요.
- **설정 앱(`Win+I`)**: 개인 설정(다크·라이트, 강조색, 투명도, 손쉬운 사용, 배경화면)과 정보(버전, CPU, 메모리, 그래픽, 디스크).
- **손쉬운 사용**: 화면 확대(`Win+=`, `Win+-`, `Win+Esc`), 움직임 줄이기, 앱 글자 크게.
- **터미널은 Ptyxis로**: 제목 표시줄을 끌어 창을 옮겨요. 창의 최대화 단추도 이제 동작해요.
- **이름만**: 부팅 메뉴, 로그인, 잠금 화면에는 소개 문구 없이 RobinOS 이름만 둬요. 라이브 USB의 BIOS 부팅 메뉴에 남아 있던 Arch 그림도 RobinOS로 바꿨어요.

### 되돌리기와 업데이트

- **스냅샷으로 켜면 알려 줘요**: 부팅 메뉴에서 스냅샷으로 켜면 "지금은 임시 상태"라는 알림과 바의 "스냅샷 N · 임시" 단추가 떠요. "이 상태로 되돌리기"를 누르면 비밀번호를 묻고 되돌려요. 시스템만 되돌리고 홈 폴더는 그대로라는 것도 함께 알려 줘요.
- **업데이트 전에 보여 줘요**: 업데이트 개수, 받을 크기, 커널이 바뀌는지, 업데이트 전에 찍을 스냅샷 번호. 데이터 요금이 붙는 연결이면 먼저 물어봐요.
- **RobinOS 파일도 업데이트로**: v0.3으로 설치한 시스템은 셸, `robinctl`, 미션 같은 RobinOS 파일도 `sudo robinctl update`로 올라가요(깃허브 릴리스 `repo`의 서명한 pacman 저장소).

### 설치한 시스템

- **방화벽**: 처음부터 켜져 있어요(ufw, 들어오는 연결 막기). `robinctl audit`이 꺼진 방화벽을 알려 줘요.
- **백업 앱**: Déjà Dup. 런처에서 "파일 히스토리"나 "백업"으로 찾아요.
- **스캐너**: SANE과 문서 스캐너. 런처의 "팩스 및 스캔".
- **펌웨어**: 라이브 USB에만 있던 소리·무선 펌웨어(sof-firmware 등)를 설치본에도 넣었고, 펌웨어 업데이트(fwupd)가 앱 스토어에 나와요.
- **BitLocker 확인**: 윈도우 옆에 설치할 때 윈도우 디스크가 BitLocker로 잠겨 있으면 복구 키를 적어 뒀는지 먼저 물어요.

### 라이브 USB

- 하드웨어 시계를 지역 시간으로 읽어서, 라이브로 써 보기만 해도 윈도우 시계가 9시간 늦어지던 문제가 없어졌어요.
- USB가 없으면 윈도우 디스크의 FAT32 파티션에서도 켤 수 있어요. 파티션을 만들고 `bcdedit`를 써야 하는 고급 방법이라 [install.md](install.md) "USB 없이 켜 보기"에만 적었어요. 실제 PC에서는 아직 확인 전이에요.

## v0.2에서 올라오려면

v0.2로 설치한 시스템은 RobinOS 파일 업데이트 저장소가 켜져 있지 않아서, v0.3의 기능을 쓰려면 새 ISO로 다시 설치해야 해요. `/home`의 파일은 미리 백업하세요. v0.3으로 설치하면 다음부터는 `sudo robinctl update`로 올라가요.

## 이렇게 확인했어요

이 버전과 같은 코드로 VM에서 아래를 통과했어요. 방법은 [testing.md](testing.md)에 있어요.

- 부팅 테스트 86장면. 그중 14장면은 스크린샷만이 아니라 상태로 판정해요(미션 1 채점, 창 최대화와 되돌리기, 터미널이 하나만 열리는지, 화면 녹화 파일, .exe 안내 창, 화면 확대, 셸 다시 띄우기, 라이트·다크 바꾸기 등)
- 설치 테스트 5단계: 라이브 → 설치기로 설치 → 스냅샷 → 스냅샷으로 켜기 → 되돌리기. 설치본의 방화벽, 백업 앱, 스캐너, 펌웨어, RobinOS 패키지, 기본 앱 확인 포함
- `robinctl`과 설치기 자동 테스트(미션 45개와 CTF 10문제를 실제로 풀어 보는 테스트 포함)
- 라이브 ISO를 CD 없이 FAT32 데이터 파티션 하나로 켜는 테스트(`scripts/partition-boot-test.sh`)

## 알려진 한계

- **실제 PC에서는 아직 한 번도 켜 보지 못했어요.** 와이파이, 소리, 그래픽, 절전은 PC마다 달라요. 실제 윈도우 옆 설치도 VM의 가짜 윈도우 디스크로만 해 봤어요. 중요한 자료는 꼭 백업하세요.
- 보안 부팅을 지원하지 않아요. 펌웨어 설정에서 꺼야 켜지고, 끄면 윈도우가 BitLocker 복구 키를 물을 수 있어요.
- 터미널(Ptyxis)에서 한글 글자 사이가 조금 벌어져 보여요.
- 화면 읽기 프로그램(Orca)은 아직 쓸 수 없어요.
- 설치기에 언어·시간대 고르기와 디스크 암호화가 없어요.
- 윈도우 전용 보안 프로그램을 요구하는 은행·공공기관 사이트는 안 될 수 있어요. 리눅스용 카카오톡은 없어요.
- 라이브 ISO에는 오피스, 앱 스토어, 백업 앱, 스캐너가 없고 설치한 시스템에만 들어가요(깃허브 첨부 파일 한도 2GiB 때문이에요).

## 내려받은 ISO 확인하기

`SHA256SUMS`의 값과 비교하고, `SHA256SUMS.sig`로 서명을 확인해요. 방법과 열쇠 지문은 [install.md](install.md) "내려받은 ISO 확인하기"에 있어요.

## 윤리

RobinOS의 보안 도구, 랩, CTF는 내 컴퓨터, 직접 소유한 시스템, 허가받은 대상에서만 써요. 자세한 기준은 [ethics.md](ethics.md)에 있어요.
