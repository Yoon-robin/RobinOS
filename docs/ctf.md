# CTF 시작하기

CTF(Capture The Flag)는 숨겨 둔 "플래그"라는 글자를 찾아내는 보안 문제 풀이예요. 문제마다 파일이나 웹 주소, 프로그램이 주어지고, 그 안에서 `ROBIN{...}`처럼 정해진 모양의 글자를 찾으면 풀린 거예요. 정해진 대상을 허락받고 공격해 보는 연습이라, 보안을 배우는 가장 재미있는 방법 중 하나예요.

## RobinOS 입문 CTF

학습 미션(특히 1~25번과 36~40번)을 끝냈다면 `robinctl ctf`로 입문 문제 10개를 풀어 보세요. 미션은 할 일을 한 단계씩 알려 주지만, CTF는 무엇을 할지 스스로 정해야 해요. 문제마다 힌트가 있고, 막히면 관련 미션을 다시 보면 돼요.

```bash
robinctl ctf                          # 문제 목록과 푼 것
robinctl ctf show 1                   # 문제와 힌트
robinctl ctf submit 1 'ROBIN{...}'    # 플래그 확인 (작은따옴표로 감싸요)
robinctl ctf reset                    # 푼 기록 지우기
```

| # | 문제 | 분야 | 이어지는 미션 |
|---|---|---|---|
| 1 | 숨은 파일 | 리눅스 | 1, 5 |
| 2 | 두 번 감싼 쪽지 | 인코딩 | 11 |
| 3 | 로그 속 이상한 요청 | 포렌식 | 15 |
| 4 | 네 자리 자물쇠 | 스크립트 | 16~20 |
| 5 | 관리자 쿠키 | 웹 | 21~25 |
| 6 | 바꿔치기된 파일 | 무결성 | 12, 39 |
| 7 | 열리지 않는 금고 | 권한 | 4, 37 |
| 8 | 약한 비밀번호 | 암호화 | 29, 40 |
| 9 | 포트 뒤의 목소리 | 네트워크 | 9 |
| 10 | 사진 속 압축 파일 | 포렌식 | 11, 14 |

문제 파일은 `~/practice/ctf`에 생겨요. 5번은 웹 연습 서버를 켜야 해요(`python3 ~/practice/web/server.py`). 9번은 `robinctl ctf show 9`를 하면 이 컴퓨터(127.0.0.1)에서만 들리는 작은 서버가 1시간 동안 떠요. 플래그는 `robinctl` 안에 해시로만 있어서, 스크립트를 읽어도 답이 보이지 않아요.

## 푸는 요령

1. **무엇을 받았는지부터 봐요.** 파일이면 `file`로 진짜 종류를, `ls -la`로 숨은 파일을 확인해요. 웹이면 `curl -i`로 응답 헤더와 쿠키까지 봐요.
2. **이상한 글자는 인코딩을 의심해요.** 끝이 `=`이면 base64, 숫자와 a~f만 있으면 16진수인 경우가 많아요. `base64 -d`, `xxd -r -p`로 풀어 봐요.
3. **"다른 하나"를 찾아요.** 로그나 목록에서 나머지와 다른 줄(다른 주소, 다른 상태 코드)이 단서예요. `grep`, `sort | uniq -c`가 도와줘요.
4. **경우가 적으면 다 해 봐요.** 네 자리 숫자는 만 개뿐이에요. 반복문으로 하나씩 시도하는 것도 실력이에요. 단, 내 문제 파일이나 허락받은 대상에만 해요.
5. **기록을 남겨요.** 시도한 명령과 결과를 메모하면 막혔을 때 되돌아보기 쉬워요. 다 풀고 나면 풀이(write-up)로 정리해 보세요. 배운 게 오래 남아요.

## 분야별 도구

| 분야 | 하는 일 | RobinOS 도구 | 프로필 |
|---|---|---|---|
| 리눅스·스크립트 | 파일 찾기, 반복 작업 | `find`, `grep`, `bash`, `python3` | 기본 |
| 포렌식 | 파일 종류, 메타데이터, 숨은 파일, 로그 | `file`, `exiftool`, `binwalk`, `strings` | `forensics` |
| 리버싱 | 프로그램 속 글자와 동작 | `strings`, `ltrace`, `strace`, `objdump`, `gdb`, Ghidra | `reversing` |
| 웹 | 요청과 응답, 쿠키, 숨은 주소 | `curl`, 브라우저 개발자 도구(F12), `gobuster`, `sqlmap` | `web` |
| 네트워크 | 포트, 패킷 | `nmap`, `ss`, `tcpdump`, Wireshark | `network` |
| 비밀번호 | 해시 대입 | `john`, `hashcat` | `passwords` |

프로필은 `sudo robinctl profile <이름>`으로 설치해요. 무거운 도구는 처음부터 깔려 있지 않아요.

## 다음 단계

입문 CTF를 다 풀었다면 이런 곳에서 이어서 연습할 수 있어요. 모두 문제를 풀라고 공개된 곳이에요.

- **웹 보안 랩**: `robinctl lab info web`. 내 컴퓨터 안의 Juice Shop과 DVWA로 진짜 취약한 웹 앱을 연습해요.
- **OverTheWire Bandit**: 리눅스 명령만으로 단계를 넘는 워게임이에요. 학습 미션 바로 다음으로 좋아요.
- **picoCTF**: 입문자용 CTF예요. 대회가 끝난 문제도 연습장(picoGym)에서 언제든 풀 수 있어요.
- **드림핵(Dreamhack)**: 한국어 강의와 워게임이 있어요.
- **TryHackMe, Hack The Box**: 가상 머신을 띄워 시스템 전체를 공격해 보는 실습이에요. 한 단계 어려워요.

## 지킬 것

- CTF 문제와 연습장은 공격해도 된다고 허락받은 곳이에요. 같은 기술을 다른 사이트나 시스템에 쓰는 건 허가 없는 공격이에요([ethics.md](ethics.md)).
- 대회에서는 대회 서버 자체를 공격하거나 다른 사람의 풀이를 방해하지 않아요. 진행 중인 대회의 플래그나 풀이는 끝날 때까지 공유하지 않아요.
- 출처를 모르는 문제 파일(특히 실행 파일)은 VM 안에서 열어요.
