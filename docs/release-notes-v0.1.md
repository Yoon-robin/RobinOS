# RobinOS v0.1 프리뷰

RobinOS는 윈도우에서 넘어와 매일 쓰면서 리눅스와 보안을 배우는 OS예요. Arch Linux 위에 Hyprland와 직접 만든 Quickshell 셸을 얹었고, 처음 켤 때부터 한국어 화면과 한글 입력이 돼요.

## 들어 있는 것

- **익숙한 데스크톱**: 아래 작업 표시줄(독), 자유롭게 띄우는 창, `Alt+Tab`, `Alt+F4`, `Win+E`, `Win+D`(바탕 화면 보기) 같은 윈도우 단축키. 독의 앱을 누르면 창이 앞으로 나오고, 앞에 있으면 최소화돼요. 런처에서 "메모장", "제어판"처럼 윈도우 이름으로 찾아도 돼요. 다크·라이트 모드와 강조 색을 고를 수 있고, 키보드만으로도 쓸 수 있어요.
- **환영 마법사**: 첫 로그인 때 테마, 한/영 전환 키, 학습 목표를 고르고 단축키를 익혀요.
- **설치기**: 라이브 화면 독의 "RobinOS 설치". 윈도우 옆에 설치하거나 디스크 전체를 쓸 수 있고, 디스크 나누기부터 한국어 설정, 스냅샷까지 알아서 해요.
- **망가뜨려도 괜찮게**: pacman으로 설치·업데이트할 때마다 전후 스냅샷이 생기고, 부팅 메뉴의 "RobinOS snapshots"에서 이전 상태로 부팅하거나 `sudo robinctl snapshot rollback`으로 되돌려요.
- **학습 미션 10개**: 리눅스 기초 5개와 네트워크 기초 5개. 터미널에서 직접 풀면 `robinctl learn check`가 확인해요. 윈도우 명령(`ipconfig`, `dir` ...)을 치면 리눅스 명령을 알려 줘요.
- **보안 실습 프로필**: `network`, `web`, `forensics`, `reversing`, `passwords`, `wireless`, `vm`. 배우는 단계에 맞춰 하나씩 설치해요.
- **로컬 웹 랩**: OWASP Juice Shop과 DVWA를 내 컴퓨터(`127.0.0.1`)에서만 띄워요. 켤 때만 돌고 재부팅하면 꺼져 있어요.
- **가상 머신에서도**: QEMU나 VMware에서 화면이 창 크기에 맞춰지고, 그래픽 드라이버 때문에 셸이 안 보이면 셸만 소프트웨어 그리기로 다시 띄워요.

## 설치

[install.md](install.md)에 있어요. UEFI 컴퓨터와 40GB 이상의 공간, 인터넷이 필요해요.

## 이렇게 확인했어요

이 버전의 ISO로 VM에서 아래를 모두 통과했어요. 방법은 [testing.md](testing.md)에 있어요.

- 부팅 테스트: 라이브 부팅(데스크톱까지 약 20초), 환영 마법사, 런처, 설치기 화면, 빠른 설정, 키보드 이동, 터미널 힌트, 미션, 바탕 화면 보기, 라이트 모드, 셸을 꺼도 다시 뜨는지, 잠금 화면
- 설치 테스트 세 가지: archinstall로 설치 후 RobinOS 입히기, 설치기로 디스크 전체에 설치, 윈도우가 있는 디스크 옆에 설치(윈도우 파티션과 부팅 파일이 그대로인지, 부팅 메뉴에 윈도우가 나오는지)
- 설치한 시스템에서: 첫 로그인, 업데이트 전후 스냅샷, 부팅 메뉴에서 스냅샷으로 부팅해 그 안에서 되돌리기, 웹 랩 실행
- `robinctl` 자동 테스트: 미션 채점, 보안 프로필, 랩, 윈도우 명령 힌트

## 알려진 한계

- **실제 PC에서는 아직 확인 전이에요.** VM에서만 검증했어요. 노트북의 Wi-Fi, 그래픽 카드, 절전은 기종마다 다를 수 있어요.
- **실제 윈도우 옆 설치도 확인 전이에요.** VM의 윈도우 흉내 디스크로는 확인했지만, 진짜 윈도우에서 부팅 메뉴와 BitLocker 복구 키 요구는 아직이에요. 중요한 자료는 꼭 백업하세요.
- 윈도우 전용 보안 프로그램을 요구하는 은행·공공기관 사이트는 리눅스에서 안 될 수 있어요.
- Qt 앱(예: Wireshark)에는 창 제목 표시줄이 없어요. 다음 버전에서 다뤄요.
- 설치한 뒤 RobinOS 자체 파일(셸, `robinctl`)을 새 버전으로 올리는 길은 아직 없어요. 시스템 패키지는 `sudo robinctl update`로 올라가요.
- 설치기에서 언어와 시간대를 고르는 기능, 디스크 암호화는 아직 없어요.
- ISO에 서명이 아직 없어요. 내려받은 뒤 `SHA256SUMS`로 확인하세요.
- 라이브 ISO에는 가벼운 보안 도구만 들어 있어요. Wireshark 화면 앱, john, hashcat, 웹 랩(Docker), 가상 머신 도구는 설치한 뒤 `sudo robinctl profile <이름>`으로 넣어요.

## 윤리

RobinOS의 보안 도구와 랩은 내 컴퓨터, 직접 소유한 시스템, 허가받은 대상에서만 써요. 자세한 기준은 [ethics.md](ethics.md)에 있어요.
