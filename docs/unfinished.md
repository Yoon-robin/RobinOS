# 미완성 기능 전체 목록

2026-10-13 사용자 요청("우리 미완성 기능 다 정리해, 빠짐없이, codex랑 같이 생각해")으로 만든 점검표예요. [tasks.md](tasks.md)는 작업 하나하나의 진행 기록이고, 이 문서는 "지금 빠져 있거나 반쯤인 것"을 영역별로 한 장에 모은 거예요. 처음 목록은 제가 읽은 것과 Codex(`codex exec`, 읽기 전용)가 따로 읽은 것을 합쳤어요. Codex의 주장은 그대로 믿지 않고 근거를 다시 확인했어요(맨 아래 "Codex 주장 확인").

마지막 점검: 2026-11-24 저녁(robin PC, 사용자 "다시 정리해 줘"). 10월 15일 뒤 끝난 작업(done.md의 T-147~T-187)을 표에서 빼고, 남은 버그는 코드를 다시 읽어 확인했어요. 정체성이 "윈도우에서 넘어오는 사람을 위한 한국어 리눅스"로 바뀌어서(2026-11-24) 우선순위도 그 사람의 첫날 기준으로 다시 봤어요. 부족한 점은 이 문서 한 곳에만 적어요. 다른 문서(design.md, roadmap.md, 릴리스 노트)는 여기로 링크만 걸어요([README.md](README.md) "문서 쓰는 규칙").

상태: **없음**(시작 전), **반쯤**(일부만 됨), **확인 안 됨**(코드는 있는데 VM 밖에서 못 봄), **버그**(근거를 확인함). 우선순위: **P0** 첫 사용자가 지금 막혀요, **P1** 첫 사용자에게 중요해요, **P2** 나중이에요. 작업 번호가 있으면 [tasks.md](tasks.md)에서 이어져요.

## 지금 어디쯤인가요

VM 안에서는 매일 쓸 만한 프리뷰예요. 라이브 부팅, 세 가지 설치(디스크 전체·윈도우 옆·파티션, 암호화 포함), 스냅샷 부팅·되돌리기·시스템 재설정, 업데이트가 묶음 검증마다 돌아요. 로드맵 7단계("실제 PC에서 매일 쓰기")는 아직이에요. 가장 모자란 건 기능 수보다 실제 PC에서 확인한 기록이에요.

## 먼저 볼 것

윈도우에서 넘어오는 사람이 첫날 막히는 순서예요.

1. **보안 부팅(Secure Boot)**: 켜진 채로는 USB가 안 켜져요. 요즘 PC 대부분이 해당돼요. 끄는 법과 BitLocker 복구 키 확인은 설치 안내와 설치기에 들어갔지만(T-147), 켠 채로 부팅하는 방법은 조사 전이에요(T-148).
2. **실제 PC 확인이 거의 없어요**: 한 대에서 "잘 된다"는 말만 있고 기종·항목 기록이 없어요(T-167). VMware로 대신 볼 수 있는 것은 [testing.md](testing.md) "VMware로 실기기 대신 확인하기"에 있고, 내장 와이파이·그래픽 드라이버·덮개·터치패드·밝기·실제 펌웨어는 VMware로도 못 봐요.
3. **진짜 윈도우 옆 설치**: 가짜 EFI·NTFS 디스크와 BitLocker로 잠근 가짜 D:로만 확인했어요. 진짜 윈도우의 GRUB 항목, 빠른 시작, OEM 복구 파티션은 몰라요(T-006). VMware에 진짜 윈도우 11을 깔면 복구 파티션 말고는 볼 수 있어요.
4. **설정 앱의 빈칸**: 해상도·주사율·여러 모니터와 사용자 계정(비밀번호 바꾸기, 계정 추가)이 없어요(T-149). 윈도우의 "디스플레이 설정"과 "계정"을 찾는 사람이 바로 막혀요.
5. **윈도우 프로그램**: `.exe`를 열면 안내 창이 대신 쓸 것을 권하고, 설치본에서는 Wine으로 실행해 볼 수 있어요(T-189, 묶음 검증 대기). 은행·공공기관 보안 프로그램과 최신 HWP 편집은 Wine으로도 안 돼요. 이건 약속하지 않는 쪽으로 정했어요([design.md](design.md) "조심할 것").
6. **업데이트 길의 약한 곳**: 서명 열쇠가 PC 한 대에만 있고, 깃허브가 안 되면 설정 앱의 업데이트 상태와 손으로 친 `pacman -Syu`가 멈춰요(`robinctl update`는 넘어가요). 아래 7번 표예요.
7. **첫인상**: 부팅 화면이 없어 커널 글자가 그대로 나오고(T-150), 한글 입력 후보 창·관리자 암호 창·커서는 아직 키트 색이 아니에요(T-188).

## 1. 부팅·설치·배포

| 항목 | 상태 | 메모 | 우선순위 |
|---|---|---|---|
| 보안 부팅 지원 | 없음 | 서명되지 않은 GRUB이라 켜진 채로는 안 켜져요. 방식 조사부터(T-148) | P0 |
| 오프라인 설치 | 없음 | 인터넷이 없으면 설치를 못 해요(`pacstrap`이 내려받아요). 설치기가 첫 단계에서 막아요 | P1 |
| ISO 크기 여유 | 반쯤 | v0.3 ISO가 GitHub 첨부 한도(2GiB)까지 약 42MiB 남았어요. 새 앱은 설치본 목록(`packages/apps.txt`)에만 넣어요(오피스, 앱 스토어, 백업, 스캐너, Wine) | P1 |
| 릴리스 서명 열쇠 보관 | 반쯤 | 개인 열쇠가 개발 PC(WSL)에 암호 없이 있어요. 오프라인으로 옮기고 지우는 건 사용자 몫이에요 | P1 |
| 다운로드 전에 핵심 제한 알리기 | 반쯤 | 사이트는 "실제 PC에서는 아직 확인 중"과 릴리스 노트 링크만 있어요. 보안 부팅·BitLocker는 설치 안내에만 있어요 | P1 |
| 레거시 BIOS 설치 | 없음 | 라이브 ISO는 BIOS로 켜지는데 설치기는 UEFI만 받아요. "UEFI만 지원"으로 정할지 | P2 |
| USB 없이 파티션으로 켜기 | 확인 안 됨 | VM에서만 통과했어요. 실제 펌웨어가 `bcdedit` 항목을 받아 주는지 몰라요(T-168) | P2 |
| 부팅 화면(Plymouth) | 없음 | GRUB 뒤에 커널 글자가 그대로 나와요. 암호화 설치의 비밀번호 화면과 함께 설계해요(T-150) | P1 |
| 라이브 ISO에서 일상 앱 체험 | 없음 | 오피스·앱 스토어·백업·스캐너·Wine은 설치본에만 있어요(용량) | P2 |
| 재현 가능한 빌드 | 없음 | ISO를 개인 PC에서 수동으로 빌드하고 서명해요. 같은 소스에서 같은 ISO가 나오는지 다른 사람이 못 확인해요 | P2 |

## 2. 설치기

| 항목 | 상태 | 메모 | 우선순위 |
|---|---|---|---|
| 진짜 윈도우 디스크 옆 설치 | 확인 안 됨 | 가짜 디스크만. 진짜 GRUB 항목, 빠른 시작, OEM 복구 파티션(T-006) | P0 |
| 설치기 안에서 윈도우 C: 줄이기 | 없음 | 지금은 윈도우 디스크 관리에서 먼저 비워야 해요. 가장 위험한 단계를 초보자가 손으로 해요 | P1 |
| 재설치할 때 `/home` 지키기 | 없음 | 이전 RobinOS 파티션을 다시 쓰면 전체를 포맷해요. 개인 파일도 지워져요(확인 상자는 있어요) | P1 |
| 디스크 전체·빈 공간 설치를 화면으로 눌러 보는 테스트 | 반쯤 | 파티션 설치(windows)는 화면에서 "설치 시작"까지 눌러요. 디스크 전체(`robinos`)·암호화는 백엔드를 바로 불러요 | P1 |
| 파티션 표가 없는 디스크 | 버그 | 디스크 전체가 NTFS·ext4·LVM·LUKS인 데이터 디스크가 그림에 "빈 공간"으로 보이고 윈도우·BitLocker 표시도 없어요. 디스크 전체 설치가 경고 없이 지울 수 있어요(`disk_layout`, 2026-11-24 다시 확인) | P1 |
| 내 파일이 든 NTFS 데이터 파티션 | 반쯤 | 윈도우가 없는 NTFS("D:")도 "만들어 둔 파티션"으로 골라져요. 지우기 확인은 받지만 비었는지 보지 않아요 | P1 |
| 비밀번호 강도 | 반쯤 | 8글자보다 짧거나 사용자 이름과 같으면 "권해요" 안내만 해요. 한 글자도 만들어져요 | P1 |
| 설치 중 전원이 꺼졌을 때 | 반쯤 | 멈춘 설치의 파티션을 다시 쓰는 길은 있어요. 전원 차단·EFI 손상은 시험한 적 없어요 | P1 |
| 설치 언어 고르기 | 없음 | `ko_KR.UTF-8` 고정이에요. 시간대는 고를 수 있어요 | P2 |
| 완전한 수동 파티션 | 반쯤 | 크기 정하기와 만들어 둔 파티션 고르기는 돼요. 별도 `/home`, 다른 리눅스와 함께, 스왑 크기는 안 돼요 | P2 |
| 설치기에서 보안 실습 프로필 고르기 | 없음 | 설치한 뒤 `robinctl profile`로 해요 | P2 |
| `RobinOS` 이름의 파티션 | 반쯤 | 형식 검사를 건너뛰어 열지 않은 LUKS·LVM도 고를 수 있어요 | P2 |
| 라이브 USB를 목록에서 빼기 | 버그 | `/run/archiso/bootmnt`로 찾아서, `copytoram`이나 파일로 부팅하면 라이브 디스크를 못 알아봐요 | P2 |
| 설치 화면의 사용자 이름 검사 | 반쯤 | 화면은 시스템 이름(`games`, `video` 등)을 몰라요. 백엔드가 시작할 때 거절해요 | P2 |
