윈도우에서 하던 그대로

Win+E로 파일을 열고 Alt+Tab으로 창을 바꿔요. 앱도 윈도우에서 부르던 이름으로 찾으면 돼요.

윈도우 이름으로 찾기

"메모장"을 찾으면 텍스트 편집기가 나와요. 윈도우의 무엇에 해당하는지도 같이 알려 줘요.

단축키

손에 익은 키가 대부분 돼요. 전체 목록은 Win+F1이에요.

.exe를 열면

바로 실행하지 않고, 대신 쓸 리눅스 앱을 알려 줘요.

작업 보기

Win+Tab으로 열린 창과 작업 공간을 한 번에 봐요.

막히는 곳에서 배워요

아래에 윈도우 명령을 쳐 보세요. RobinOS 터미널과 같은 표로 리눅스 명령과 연습할 미션을 알려 줘요.

robin@robinos ~ >

Enter를 누르면 답이 나와요. 아무것도 실행하지 않아요.

robin@robinos ~ > ipconfig
ipconfig 명령은 윈도우용이에요. 리눅스에서는
  ip a  IP 주소와 네트워크 장치를 보여 줘요

망가지면 되돌려요

설치나 업데이트를 할 때마다 그 직전 상태를 스냅샷으로 남겨요. 문제가 생기면 부팅 메뉴에서 그때로 켜면 돼요.

  1. 업데이트 전에 저절로 스냅샷
  2. 부팅 메뉴에서 그 스냅샷으로 켜기
  3. 알림의 "이 상태로 되돌리기"

스냅샷은 시스템만 되돌려요. 사진과 문서는 백업 앱으로 USB 디스크에 따로 남겨요.

처음부터 한국어로

켜자마자 한/영 키로 한글을 쓰고, 메뉴와 안내도 모두 한국어예요.

켜자마자

  • 한글 입력 한/영 키와 오른쪽 Alt
  • 화면 녹화 Win+Alt+R
  • 손쉬운 사용 화면 확대, 큰 글씨, 움직임 줄이기

설치하면

  • 앱 스토어 Flathub의 앱
  • 오피스 LibreOffice
  • 프린터와 스캐너 대부분 드라이버 없이
  • 방화벽 처음부터 켜져 있어요
  • 백업 개인 파일을 USB 디스크에

설치하기 전에 먼저 켜 봐요

USB로 켜면 지금 쓰는 컴퓨터를 건드리지 않고 써 볼 수 있어요.

  1. ISO 내려받기

    GitHub 릴리스에서 받아요. 체크섬과 서명으로 받은 파일을 확인할 수 있어요.

  2. USB로 켜기

    Rufus나 Ventoy로 USB에 담아요. USB가 없으면 윈도우 디스크의 빈 파티션에서도 켤 수 있어요.

  3. 써 보고 설치하기

    마음에 들면 독의 "RobinOS 설치"를 눌러요. 윈도우 옆에도 설치돼요.

ISO 내려받기 설치 안내 →

필요한 것

  • UEFI로 켜는 PC
  • 보안 부팅 끄기
  • 디스크 40GB 이상

지금은 미리 보기예요

가상 머신에서는 바뀔 때마다 켜고 설치까지 시험해요. 실제 PC에서는 아직 시험하지 못했어요. 중요한 자료가 있는 컴퓨터에는 설치하지 마세요.

써 보다 문제가 보이면 GitHub 이슈로 알려 주세요.

RobinOS

GPL-3.0 오픈 소스예요. Arch Linux, Hyprland, Quickshell을 바탕으로 만든 개인 프로젝트이고, 세 프로젝트와 공식 관계는 없어요. 이 페이지는 쿠키나 방문 기록을 남기지 않아요.
